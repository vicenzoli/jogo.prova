Este é o classico jogo da cobrinha, porem em uma versão ainda mais simples.
Mova seu quadradinho verde até as frutas para ganhar pontos, mas tome cuidado!
Colidir com as bordas da floresta resulta no fim do jogo!

(Essa cobrinha ta na puberdade e tem um metabolismo muito acelerado, impedindo que ela cresça quando coma)
